# Quora CRUD App

A simple Quora-style CRUD application built using Node.js, Express.js, and EJS.

## Features

- Create a new post
- View all posts
- Edit existing posts
- Delete posts
- Server-side rendering with EJS
- RESTful routing

## Tech Stack

- Node.js
- Express.js
- EJS
- HTML
- CSS
- UUID

## Project Structure

│── views/
│── public/
│── index.js
│── package.json
